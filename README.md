> Uma plataforma web moderna, minimalista e elegante para estudos bíblicos, leitura devocional e orações. Inspirada no design e fluidez dos melhores SaaS do mercado (estilo **Notion** e **Spotify**).

---

## ✨ Funcionalidades Principais

### 1. 🌟 Página de Vendas / Landing Page Inicial de Alta Conversão
- **Hero Section**: Apresentação de valor, prova social (+25.000 vidas) e chamadas para ação.
- **Demonstração Interativa (Live Mockup)**: Abas dinâmicas para explorar Leitor, Planos, Caderno e Mural de Orações.
- **Bento Grid de Benefícios**: Visualização moderna de cada recurso central.
- **Comparativo Direto**: Dorafy vs Apps Convencionais (zero anúncios vs poluição visual).
- **Tabela de Preços**: Dorafy Gratuito e Dorafy Pro (com alternador Anual/Mensal).
- **FAQ Acordeão & Prova Social**: Depoimentos reais de pastores e líderes.

### 2. 🏠 Início (Hoje) — Dashboard Devocional
- **Versículo do Dia** em destaque com citação estilizada, cópia, compartilhamento e salto direto para o capítulo.
- **Ofensiva & Frequência (🔥 14 dias seguidos)** com rastreador semanal e meta diária.
- **Progresso do Plano Ativo** (ex: *Evangelhos em 30 Dias*) com barra percentual e leitura rápida do dia.
- **Mini-player Devocional em Áudio** com estética inspirada no Spotify.
- Acesso rápido a novas notas, pedidos e histórico recente.

### 3. 📖 Bíblia Sagrada (Leitor Distraction-Free)
- Seletor dinâmico de Livro, Testamento e Capítulo com número em grade.
- Suporte a múltiplas traduções bíblicas (**NVI**, **ARA**, **NVT**, **NAA**).
- **Controles Tipográficos**: Ajuste de tamanho da fonte (A- / A+) e alternância entre fonte **Serifada** (*Newsreader/Lora/Georgia*) e **Sem Serifa** (*Inter*).
- **Marca-Texto Colorido**: Destaque em **Amarelo Sol**, **Verde Sálvia**, **Rosa Suave** ou **Azul Céu**.
- Criação de anotações contextualizadas diretamente a partir do versículo clicado.

### 4. 🌱 Planos & Trilhas Devocionais
- Catálogo de planos temáticos (*Evangelhos em 30 Dias*, *Ansiedade e Paz*, *Sabedoria em Provérbios*, *Fundamentos da Graça*).
- Cronograma diário com checkmarks e celebração festiva de confetes (`canvas-confetti`).
- Atalho para abrir e ler a passagem do dia na Bíblia com um toque.

### 5. ✍️ Caderno de Estudos & 🙏 Mural de Orações
- **Caderno de Notas**: Categorização por tags (*Culto*, *Estudo Pessoal*, *Devocional*, *Teologia*), sistema de fixação no topo (`pin`), edição e exclusão.
- **Mural de Orações**: Pedidos divididos por categorias (*Família*, *Saúde*, *Espiritual*, etc.), contador de intercessões com botão *"Orar Hoje"*, e fluxo de oração respondida com registro de testemunho.

### 6. 👤 Perfil, Metas & Dorafy Pro
- Slider interativo de meta diária de leitura (minutos/dia).
- Heatmap de constância devocional das últimas 4 semanas.
- Modal de assinatura **Dorafy Pro** com detalhes de faturamento e recursos exclusivos.
- Backup e exportação dos dados do usuário em formato JSON.

### 7. ⚡ Recursos Globais Extras
- **Command Palette (`⌘K` ou `Ctrl+K`)**: Busca rápida e navegação instantânea estilo Spotlight.
- **Modo Escuro / Claro**: Suporte nativo a Dark Mode suave (*matte charcoal / soft sage*).
- **Layout Responsivo**: Barra lateral colapsável no Desktop e navegação inferior ergonômica no Mobile.

## 🛠️ Stack Tecnológica

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Efeitos de Celebração**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Tipografia**: Google Fonts (*Inter*, *Newsreader*, *Lora*, *Cinzel*)

## 🚀 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/elcuririn01-blip/dorafy.git
   cd dorafy
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   ```
   http://localhost:5173
   ```

5. **Para gerar o build de produção:**
   ```bash
   npm run build
   ```
